# SQL

### How to connect SQL in C# 
1. Required Namespace
```cs
using System;
using System.Data;
using System.Data.SqlClient;
```

2. Connection String
```cs
string connectionString = "Server=.;Database=YourDB;Trusted_Connection=True;";
```
**Replace :**
* YourDB → your database name
* . → local SQL Server

3. Full Example
```cs
using System;
using System.Data.SqlClient;
class Program
{
    static void Main()
    {
        string connectionString = "Server=.;Database=YourDB;Trusted_Connection=True;";
        using (SqlConnection con = new SqlConnection(connectionString))
        {
            con.Open(); // open connection
            string query = "SELECT Id, Name FROM Students";
            SqlCommand cmd = new SqlCommand(query, con);
            SqlDataReader reader = cmd.ExecuteReader();
            while (reader.Read())
            {
                Console.WriteLine(reader["Id"] + " " + reader["Name"]);
            }
        }
    }
}
```

- SqlConnection -> Connect to database
- Open() -> Open connection
- SqlCommand -> SQL query holder
- ExecuteReader() -> Run SELECT query
- SqlDataReader -> Read data row by row

⸻

### INSERT / UPDATE / DELETE

Use : ExecuteNonQuery()
```cs
string query = "INSERT INTO Students(Name) VALUES('Deep')";
SqlCommand cmd = new SqlCommand(query, con);
int rows = cmd.ExecuteNonQuery();
Console.WriteLine("Rows affected: " + rows);
```
⸻

Parameterized Query

👉 Avoid SQL Injection
```cs
string query = "INSERT INTO Students(Name) VALUES(@name)";
SqlCommand cmd = new SqlCommand(query, con);
cmd.Parameters.AddWithValue("@name", "Deep");
cmd.ExecuteNonQuery();
```
⸻

🔥 Best Practice

✔ Always use using (auto close connection)
✔ Use parameters instead of string concatenation
✔ Handle exceptions (try-catch)
