# Let:
- create a temporary variable

**Query Syntax:**
```cs
var result = 
    from s in students
    let bonus = s.Marks + 10
    select new
    {
        s.Name,
        bonus
    };
```

**Method Syntax Equivalent:**
```cs
var result = 
        students.Select(s => new {
        S.Name,
        bonus = s.Marks + 10
    });
```
