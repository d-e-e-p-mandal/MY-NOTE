##### DTO Used with SQL :

**Example SQL Query:**
```sql
SELECT Id, Name
FROM Employees
```

**DTO Class:**
```cs
public class EmployeeDto
{
    public int Id { get; set; }
    public string Name { get; set; }
}
```

**Raw SQL + DTO Example:**
```cs
List<EmployeeDto> employees = new List<EmployeeDto>();
using(SqlConnection con = new SqlConnection(connectionString))
{
    con.Open();
    string query = "SELECT Id, Name FROM Employees";

    using(SqlCommand cmd = new SqlCommand(query, con))
    {
        using(SqlDataReader reader = cmd.ExecuteReader())
        {
            while(reader.Read())
            {
                EmployeeDto dto = new EmployeeDto();
                dto.Id = Convert.ToInt32(reader["Id"]);
                dto.Name = reader["Name"].ToString();

                employees.Add(dto);
            }
        }
    }
}
```

**Why DTO Used?**  
>Suppose table has:

    - Id
    - Name
    - Salary
    - Password
    - Address
>But API only needs:

    - Id
    - Name

>DTO sends only required data.


**Benefits of DTO:**
- Benefit:	Explanation
- Security:	Hide sensitive fields
- Performance:	Transfer less data
- Clean API:	Only needed fields
- Separation:	Entity != Response model
