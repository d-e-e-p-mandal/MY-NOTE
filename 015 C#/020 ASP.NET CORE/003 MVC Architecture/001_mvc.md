
🏗️ MVC ARCHITECTURE (VERY SIMPLE)

⸻

🔹 1. What is MVC?

👉 MVC = Model + View + Controller

⸻

🧠 Easy Meaning

Part	Meaning
Model	Data
View	UI (what user sees)
Controller	Logic (controls everything)


⸻

🔹 2. MVC Request Flow

👉 How it works:

User → Controller → Model → View → User

👉 Simple:
	1.	User sends request
	2.	Controller handles it
	3.	Gets data from Model
	4.	Sends to View
	5.	User sees result

⸻

🔹 3. Controllers and Actions

👉 Controller = Handles request

👉 Action = Method inside controller

⸻

📌 Example

public class HomeController : Controller
{
    public IActionResult Index()
    {
        return View();
    }
}

👉 Index() = Action

⸻

🔹 4. Views (Razor Syntax)

👉 View = UI (HTML page)

👉 Razor = C# inside HTML

⸻

📌 Example

<h1>Hello @Model.Name</h1>

👉 @ is used for C#

⸻

🔹 5. Models

👉 Model = Data class

⸻

📌 Example

public class Employee
{
    public string Name { get; set; }
}


⸻

🔹 6. ViewData, ViewBag, TempData

👉 Used to pass data

⸻

📌 Simple Difference

Type	Use
ViewData	Pass data (dictionary)
ViewBag	Pass data (dynamic)
TempData	Pass data between pages


⸻

📌 Example

ViewBag.Name = "Deep";


⸻

⸻

🧠 Layout

👉 Common design (header, footer)

Same layout for all pages


⸻

🧠 Partial View

👉 Small reusable part

Navbar / Footer reuse
